# Learning resources

- [TypeScript for Java/C# Programmers](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes-oop.html) is a quick intro about how TS differs from Java and C# in its treatment. One insight is that the types are more of a set of possible values than being fixed to one and that when deciding if assignment can happens, TS looks at the structure to decide if that operation would be allowed or not.
- After that the [Typescript handbook](https://www.typescriptlang.org/docs/handbook/intro.html) is a good resource to look into.
